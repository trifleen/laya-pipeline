The setup

Where every byte lives

A Mixture-of-Experts model uses only ~3B of its 35B parameters per token. The parts every token needs stay on the GPU; the 256 experts per layer stay in RAM and are computed on the CPU while generating. Reading a prompt is different: each batch of up to 2,048 tokens copies all RAM experts over PCIe once.

Next questions

  • Phase 1: which experts does the router pick per token? If a few experts per layer cover most picks, a hot-expert cache on the GPU is worth building.
